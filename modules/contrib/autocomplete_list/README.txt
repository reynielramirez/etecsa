INTRODUCTION
------------

This module provides a widget for a multi-valued entity reference field.
It is represented as an autocomplete field with values organised as a list;
each selected item can be removed before the entity is saved.

 * For a full description of the module, visit the project page:
   https://www.drupal.org/project/autocomplete_list

 * To submit bug reports and feature suggestions, or to track changes:
   https://www.drupal.org/project/issues/autocomplete_list


REQUIREMENTS
------------

Drupal 10.3 or later, Drupal 11, or Drupal 12.


INSTALLATION
------------

 * Install as you would normally install a contributed Drupal module. See the
   Drupal User Guide for installation instructions.


CONFIGURATION
-------------

No configuration is needed.


SECURITY
--------

 * Report potential security vulnerabilities privately through the
   "Report a security vulnerability" link on the project page. Do not report
